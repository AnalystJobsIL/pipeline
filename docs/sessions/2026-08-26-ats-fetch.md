## What was measured and turned into code

**The scraper's overnight verdict reaches board health (BACKLOG 154).** `fetch_scrape`
returns `[]` for a walled page and an honestly empty one alike, so `health.stale_reason`
could never say `fetch-error` for a scrape row and every one read as `regressed-to-zero`.
`health.record` now reads `cloud_state/scrape_rot.json` — the file `refresh_scrape_cache.py`
writes at 00:00 and nothing read — for scrape rows whose cache is empty, through one pure
predicate, `health.overnight_verdict(entry, today)`:

| the rot says | health writes | the mail says |
|---|---|---|
| `why: error`, fresh (`last` ≤ 2 days) | `fetch-error`, `error: scrape: http:403 (1 night)` | `new: Akamai: fetch-error` · `2 fetch errors (Akamai: scrape: http:403 (1 night); …)` |
| `why: empty`, `found > 0` | nothing (a measurement: roles found, none in Israel) | nothing — and never `cleared:` (the same rule the Workday zeros have) |
| `why: empty`, `found 0` · no entry · stale · malformed | `regressed-to-zero`, as before | unchanged |
