## 1. `596` was twelve rows, and nine of them had already been parked once

The item named five. The census that answers it — an ACTIVE row whose registrable domain

GENECIT, Greylock Partners, hms - Strategic Financial IT, John Bryce Solutions, Mars Antennas
And Rf Systems, TOTSAOT - Human Resources, Y Axis Global. Nine carried the same two segments in
their own note: `wrong-url <date>: board names X; needs re-resolution`, then `listing-hunt
<date>: verified N IL via <the same host>`.

That is the mechanism, and it is why "park each one" had not worked. `queue_pipeline
--verify-existing` parks a NOT-THEIRS row and clears its address; `needs re-resolution` is a
hunt-pool token; the 19:00 hunt searches the name, finds the same host on a sibling path, and
activates. On an ordinary host its identity gate is `identity_ok` = `not is_foreign`, and
`company_identity.verdict("Mars Antennas And Rf Systems", "careers.mars.com")` is `weak` — the
word `mars` is in the domain, the other words are not — and nothing in the repo consumes
`weak` (BACKLOG 43). The ledger that remembered the read is keyed on the exact url it read
(`/us/en/search-results?keywords=Israel`); the row held `/us/search-results`.

**What shipped: a declaration, the way `not_tenants` already does it for ATS hosts.**
`identity_facts.not_domains` (refuse-only, `host_matches` compares the whole host or a
dot-bounded tail, never `registrable()`, which returns the bare label) is consumed in exactly
one place, `company_identity.verdict`, which answers `mismatch`; `is_foreign` follows, and every
gate that already reads it refuses with no new branch. `validate()` refuses an ACTIVE row on
its own `not_domains`, so declaring forced the parks into the same commit.

Rejected, on two numbers: a veto inside `identity_ok` that reads the ledger. The ledger is
exact-url keyed (it would have missed Mars, one of the five the item named), and the gates are
pure functions that `--explain`, the tests and the mutation harness call offline — a state
file under them is the coupling this module's docstring refuses. And the census itself had to
compare the domain WITH its suffix: the first version used `registrable()` and put `Adscale`
in the class (AdScale's own `adscale.com`, ledger `ok`, folded into Adscale Tech's
`adscale.tech`) — 13, one innocent. Pinned.
