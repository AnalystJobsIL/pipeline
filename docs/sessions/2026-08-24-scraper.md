## The defects

### 1. Error was indistinguishable from empty
`scrape()` caught every navigation exception at the old line 251 and returned `[]`; the main
document's HTTP status was never read. So `refresh_scrape_cache`'s `jobs is None` branch —
carry-forward, `error` rot, parking — was dead code, and a 403 night deleted a company's jobs
from the cache while the product read "no openings".
**Fix.** `scrape_universal` is split into `_render(url)` (Playwright only; returns a `Rendered`
bundle with `http_status` and an `error` code) and `_extract(...)` (pure; the five strategies,
first hit wins). `scrape_result()` returns `ScrapeResult(jobs, status ∈ ok/empty/error, error,
strategy, rescued, …)`; `scrape()` is its list-only wrapper and still never raises (`resolve_deep`
calls it bare; `tests/test_registry.py` monkeypatches it with a two-argument lambda).
**Pinned by** `test_scrape_result_tells_a_broken_page_from_an_empty_board` (20 rows),
`test_scrape_never_raises_and_scrape_result_reports_the_failure`,
`test_refresh_carries_jobs_forward_on_error_but_never_on_empty`.

### 2. Sequential, and one company unbounded
111.6 min a night for 428 rows; Ford took 368 s (45 s goto + 12 s network-idle + 25 position pages × 12 s).
**Fix.** `refresh_scrape_cache` runs a `spawn` process pool (`SCRAPE_WORKERS`, default 4), one
Playwright per process, recycled by hand every `workers × 25` rows; a per-company `Deadline`
(`SCRAPE_COMPANY_BUDGET_S`, 150 s) clamps every network wait; the position-page timeout is 8 s.
Bookkeeping happens in the parent in registry order, so the pool and the inline path produce
byte-identical output (`test_refresh_pool_and_inline_paths_build_the_same_cache`).
CPython's `max_tasks_per_child` was tried first and **hung the full rehearsal at exactly
4 × 25 = 100 rows** (0 Chromium processes, log frozen for four minutes) — hence the manual
chunking (`test_refresh_pool_runs_a_module_level_worker_under_spawn` proves recycling).

### 3. Nothing about the scrape reached the email
The workflow stamped `collect` bare, `if: always()`, after the script; `stages.stamp()` replaces
the entry, so even a script that stamped counts would have lost them. `scrape_rot.json` was read
by nothing; `fetch_scrape` cannot fail; `health.py` exempts scrape rows.
**Fix.** The script stamps `collect` itself on every exit path with `rows scraped with_jobs empty
no_il errors carried unprocessed parked workers minutes` and an `alarm` token only when something
is wrong; the digest already prints `stages.summary()` verbatim. The workflow step is gone (a
crashed script no longer reports "collect: TODAY"). Pinned by
`test_refresh_stamps_collect_with_counts_the_digest_renders` (all three renderers) and
`test_no_workflow_step_restamps_collect_after_the_refresh`.

### 4. Non-atomic writes → `pipeline.atomic.write_json` (`test_atomic_write_json_leaves_no_partial_file`).

### 5. No side-effect-free local mode
Any local run parked rows in the real registry. **Fix.** `--only/--limit/--only-missing/--shard`
scope a run and scoped runs write nothing (`--apply` merges hits into the cache, additively);
`--dry-run` for a full read-only rehearsal; `SCRAPE_CACHE_OUT` / `SCRAPE_ROT_OUT` /
`SCRAPE_STAGES_OUT` redirect the three outputs. `test_refresh_scoped_and_dry_runs_write_nothing`.

real pages that added **18 entries, all run-together card blobs**: Nebius 1 (same URL as a clean
twin), VAST Data 1 (a United States role stamped `"EngineerIsrael"`), Port.io 16 — 6 US roles

`test_scrape_strategies_stop_at_the_first_one_that_finds_jobs`.
