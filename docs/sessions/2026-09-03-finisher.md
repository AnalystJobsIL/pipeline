### The hazard the design had to answer: the gate reads the text before anything knows whose it is

`_classify` calls `_relevance` at the top; the **shared-text guard is eighteen lines later**
(`:855-868`), and it is the first thing that knows a description is one careers PAGE stored as
every posting's text. Six companies were in that state on 2026-08-28 and Get SAT had ten roles
sharing one 4,000-character blob. Unguarded, one blob containing `data analytics` and `SQL`
would demote **every** refused title at that employer.

Reordering was rejected on a measured risk, not a preference: hoisting the guard above the
gate lets a *refused* row claim `self._text_owner` first and blank a *passing* role's
description — a live regression bought for nothing.

What shipped instead: **an appeal whose evidence was another posting's page is not an appeal.**
When `shared` fires, a title that is `signal` ONLY because of `_desc_appealed` takes back the
hearing and gets the refusal the gate would have given on the title alone. It is asked as
*what would `_relevance` have said with no text* — never "did the description arm fire" — so a
title carrying its own analytics signal keeps its hearing. Both heads, because the comment
above `judge_backfill`'s deterministic head requires them to stay in step, and the backfill is
the arm more likely to publish a `signal` cell for a row it then rejects.
